# Visual Precision Ledger

## Accepted Direction

The accepted concept combines an astronomical theorem engine, sculpted brass
nodes, dark observatory surfaces, teal state feedback, parchment learning
plates, and the selected geometric Gauss identity. The later product direction
supersedes the concept's radial-ring navigation: progression must be a single
continuous, sinuous path with off-path landmarks.

## Composition Contract

| Element | Contract | Verified implementation |
|---|---|---|
| Primary surface | Map fills the experience; UI overlays it | Full-screen star field and continuous path |
| Subject choice | Math and Physics visibly separate | Persistent switch on Map and Study |
| Progression | One readable path, not disconnected circles | Custom continuous curve through stable set nodes |
| Hierarchy | Sections and units remain visible | Section chips, unit headers, Study atlas |
| Landmarks | Large objects sit beside the route | Theorem-engine/orrery objects outside node flow |
| Mobile chrome | Floating, glass, thumb-reachable | Rounded blurred footer with safe-area inset |
| Desktop chrome | Floating rail and inspector | Full-height glass rail plus contextual inspector |
| Questions | Warm paper against astronomical field | Parchment plate with live Persian/math content |
| Identity | Geometric/philosophical mark and artistic name | Theorem Star plus authored Gauss wordmark |
| States | Brass current, teal completion/reflection | Consistent across nodes, metrics, controls |

## Responsive Evidence

- 411×820: Map, Study, Insights, and Study Room release captures.
- 1440×900: Map inspector and two-column Study atlas.
- 1080×2400 Android: native Map, Study, Study Room, and ink.
- Widget tests cover 320×640 with 1.5× text scale, reduced motion, and tablet
  layout without render overflow.

## Accessibility and Integrity

- App chrome is live English text; Persian learning content keeps its original
  direction and Vazirmatn fallback.
- Flattened wordmark is represented as one semantic image labeled `Gauss`.
- Interactive controls retain live semantics, focusability, and state.
- Ink is opt-in so scrolling and screen-reader interaction remain available.
- Reduced motion collapses decorative durations without changing behavior.
