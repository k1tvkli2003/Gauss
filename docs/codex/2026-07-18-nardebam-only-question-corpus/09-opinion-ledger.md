# Product and Design Opinion Ledger

This ledger records high-impact recommendations from the ideas, modernize,
style, anatomy, and gamification reviews and whether they were adopted.

| Opinion | Decision | Rationale |
|---|---|---|
| Make the island/orrery map the product, not a dashboard card | adopted | Stronger orientation and emotional identity |
| Separate Math and Physics at the top level | adopted | Prevents mixed curricula and supports focused routes |
| Use Section → Unit → small set hierarchy | adopted | Makes 3,672 questions navigable and resumable |
| Replace radial planets with one winding path | adopted | Matches the explicit product direction and improves sequence clarity |
| Place large theorem objects beside the path | adopted | Adds spectacle without blocking progression |
| Use a floating glass footer/rail | adopted | Keeps navigation present without flattening the astronomical field |
| Decompose visuals into backgrounds, marks, nodes, landmarks, and live UI | adopted | Preserves fidelity, responsiveness, accessibility, and maintainability |
| Use an artistic wordmark rather than a generic app-name string | adopted | Creates a recognizable identity while retaining a semantic label |
| Use Manrope for English with Vazirmatn fallback | adopted | Modern geometry plus reliable Persian coverage |
| Let users draw directly on the question and in a separate sheet | adopted | Supports real mathematical work at two spatial scales |
| Make drawing opt-in and instantly clearable | adopted | Protects scrolling, selection, and accessibility |
| Score source answers and award XP immediately | rejected | Answer mappings are not independently validated |
| Lock later chapters behind correctness | rejected | Would turn an unverified mapping into a false mastery gate |
| Add public streaks, leagues, or social pressure | rejected | Conflicts with private single-user scope |
| Bake the entire screen into one generated image | rejected | Would destroy live data, interaction, semantics, and responsive behavior |
| Use generic Material icons as the main identity | rejected | Product-specific geometric symbols carry more meaning |
| Put every decorative element in CustomPainter | rejected | Dedicated raster/SVG assets are more faithful where illustration matters |

## Quality Bar

The adopted system favors product truth over superficial gamification:
beautiful progression, private reflection, clear review, and delightful motion
are retained; fabricated correctness, coercive retention loops, and inert
mockup composition are not.
