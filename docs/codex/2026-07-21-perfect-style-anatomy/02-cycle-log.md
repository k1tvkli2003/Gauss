# Perfection cycle log

## Cycle 1 — release identity

Candidates:

1. Fail-closed protected release signing.
2. Web-safe Vault capability boundary.
3. Expanded-map visual composition.

Selected first: release identity, because a debug-signed artifact breaks the
Android update chain and can strand local data. The Gradle release surface now
requires all protected signing inputs and contains no debug fallback. A
contract test guards the rule. An unsigned release invocation was deliberately
run and rejected with the fail-closed message.

## Cycle 2 — cross-platform truth

Selected next: web-safe Vault. The service now exposes its real capability,
web startup performs a no-op before any native file API is reached, the Vault
route renders a deliberate browser boundary, and the Insights action appears
only where the capability exists.

## Cycle 3 — modal anatomy

Selected next: first-run isolation. The tour moved from the map body to the app
shell so mobile navigation and desktop rail are absent while the modal is
active. Background input and semantics are excluded until dismissal.

## Cycle 4 — continuous-path composition

Three candidates were compared: larger nodes alone, a central hero that would
compete with the route, and proportional landmark plus instrument geometry.
The third option won because it retains path clarity while restoring the depth
of the accepted Orrery direction. The map now uses width-class node scale,
stronger path rhythm, a first-screen Theorem Engine beside the route, recurring
landmarks, and low-contrast astrolabe scaffolding behind the path.

## Cycle 5 — language and responsive integrity

Engineering phrases such as “preserved coordinates” and “source questions”
were replaced with concise learner-facing language. The trust boundary remains
explicit: provided answers are reference material and are not certified by
Gauss. A 200% text / reduced-motion test exposed a real compact-header overflow;
the header now condenses to the Theorem Star, subject switch, and level only at
that accessibility scale. Normal-density composition is unchanged.

## Cycle 6 — evidence and release continuity

The final web bundle was exercised across phone, tablet, and desktop routes
with zero console or page errors. The protected-key Android APK updated the
existing v90 installation to v105 while retaining its original first-install
timestamp. Phone and 800dp native-tablet screenshots were visually inspected.
The full artifact verifier proved question and media parity across source,
Flutter assets, web output, and APK.
